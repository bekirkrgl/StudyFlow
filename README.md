

\# StudyFlow



StudyFlow, üniversite öğrencilerinin derslerini,

çalışma planlarını ve akademik görevlerini

tek bir uygulama üzerinden yönetebilmelerini

amaçlayan bir mobil uygulama projesidir.



\## Kullanılacak Teknolojiler



\- Flutter / Dart

\- ASP.NET Core Web API (C#)

\- Microsoft SQL Server

\- Entity Framework Core

\- JWT

\- Swagger



\## Proje Geliştirme Süreci



Proje, IOS 1 dersi kapsamında 9 haftalık bir

geliştirme planına göre yürütülmektedir.



\### 1. Hafta - Proje Analizi ve Planlama



Bu hafta kapsamında:

\- Projenin amacı ve kapsamı belirlendi.

\- Fonksiyonel gereksinimler hazırlandı.

\- Fonksiyonel olmayan gereksinimler hazırlandı.

\- Kullanılacak teknolojiler ve sistem mimarisi planlandı.



Analiz belgeleri `docs` klasöründe bulunmaktadır.
